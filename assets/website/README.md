# Website app UI images

`screenshots/` contains 14 unchanged copies of the retained app UI design images,
renamed in website tour order. No AI-generated advertising artwork is included.

These are existing design references, not newly captured screenshots of the
current release. They may differ from the implemented app; do not describe them
as verified current-build captures.

Use images 01–04 to introduce the schedule, medicine list, medicine details and
history. Images 05–08 show the medicine setup flow, 09 shows Settings, 10–12 show
profiles, and 13–14 show profile and reminder onboarding.

For current implementation details and limitations, use
`docs/SETTINGS_ARCHITECTURE.md` and the app source rather than inferring features
from these design images. In particular, reminder timing is not guaranteed.

The current app icon is `assets/images/icon.png`; the configured display name is
**Dose Tracker**. Old-logo notification and old-name welcome images are excluded.
